# Quest chain template for Apocalypter Quests
#
# Copy the blocks you want into quests.txt (anywhere below the header comments), rename the ids and edit the
# text. Every block starts with a [unique_id] line. Lines starting with # are ignored. Delete the keys you don't need:
# each one has a default.
#
# How a chain behaves:
#  * Every step has `chain = <same name>`. Steps 2, 3 ... also have `after = <id of the step before>`.
#  * A step is done ONCE per save slot, never offered again afterwards.
#  * It is ALWAYS offered, before any ordinary or random job, when you ask an NPC for work who is allowed by the
#    `giver` line, once the step before it is done. The only exception: if a different NPC offered that same step
#    in the last 24 in-game hours (setting [Quests] ChainOfferGameHours), it waits.
#  * A step can still be refused by the usual things: the NPC is on cooldown, you already carry too many jobs, the
#    giver's faction is hostile, or the step needs something that doesn't exist right now (needenemy / needpoi,
#    a goto with no unfound place nearby ...).
#  * Placeholders for texts: {n} {item} {target} {reward} {have} {progress} {giver} {dist} {dir} {radius} {poi} {place} {minutes}
#  * type is one of: fetch | kill | goto | talk | clear | takeover | deliver  (see the header of quests.txt for what
#    target / count / distance / radius mean for each type).
#  * Kill steps: bodies of the kills brought back to the giver pay a bonus ([Kills] BodyBonus); no need to write that.
#  * Dialogue-file (Talk) users can also hand out a step with  action = quest.give:<id>  and react to the flags
#    quest_<id>_active / quest_<id>_done / quest_<id>_failed.
