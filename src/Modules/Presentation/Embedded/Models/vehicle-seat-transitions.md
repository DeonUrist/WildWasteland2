# Vehicle seat transition clips

`vehicle-seat-transitions.bundle` contains five standalone humanoid clips built for Windows64 in Unity 2020.3.49f1.

- WWW3's `finned_cruiser` uses `Anim_CarEnterDriver03`, `Anim_CarEnterPassenger03`, `Anim_CarExitDriver03`, and `Anim_CarExitPassenger03` from Tactical Car Driving by Wolff's Studio.
- WWW3's `JumpOutRoll.fbx` contains the Mixamo `Falling_To_Roll_2` take.

The bundle uses the source humanoid mappings and frame ranges. The four seat takes bake horizontal root motion into the pose, and the roll retains its source import settings.
