ReplacementGuard retains a plain data model; HUD owns notice drawing and the GUI job.

The Patrols warning toggle is removed as required by the plan.
- `Fixes.Install/Remove` explicitly manages HealthStacks, ColorGrading, ITweenGuard, QuietFsm, InventorySupplies, VehicleLoadPlacement and PauseCursorFix. Each has idempotent installation and teardown. Private `FixOwner` registration tokens scope patches/hooks/jobs without registering extra user modules. Vehicle placement removes its exact named loading hold and restores a held body. DuplicateRigidbody retains the accepted optimization-feature lifecycle.
- `ReleaseInfo` owns version discovery; HUD only forwards the existing coroutine and presents the resulting release URL. `ModuleRegistry` is the sole Core composition root naming module types. Debug, Compatibility and Saves initialize before consumers. Plugin no longer invokes save-framework or Vistas implementation types; coordinator-owned session integration remains intact.
