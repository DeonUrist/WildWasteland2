## 3. Unification (goal 3) - what was and was not done
- One appearance service: `CharacterAppearance` (ICharacterAppearance) over Women of Wasteland + crew aliases (`CrewAppearance.Dress` now
  calls the female body directly; same rules). Player Gungirl/Shoota models come from `WomenFeature.Paths` (same module, no service hop).
- One weapon-key rule: `ApBody.WeaponKey` = `Props.Norm` (identical text rule; unused `IsPistol` deleted, A3-6).
- Shared rig helpers `CharacterRig` (upper-body mask - cached, Body used to create a new one per body -, bone turn in a character frame,
  pair yaw, two-bone arm lift) used by both the player's Body/Loco and ModAPI characters (identical maths).
- Weapon lowering (Guns WeaponTransition Pose) unified into `IWeaponPose` (6).
- **Not done: the single character driver** (README 6.1/13: player animated by ModCharacter+CharPlan through a PlayerInputAdapter). The player
  body and the crawl / traversal / seat parts (B06) share the body's PlayableGraph; replacing it needs in-game iteration that this package
  cannot do. `[Presentation / Debug] Legacy player driver` is therefore not added (there is no second path). NPCs already have the id-based
  driver API (`ICharacterPresentation`). Proposal: a follow-up package with Denis testing (question Q1, request B05-11).
- Model builders (player `Model` vs Gungirl skin swap) both use Core `Gltf`/`Bindposes`; they serve different jobs (player mesh variants vs
  NPC skin swap) and stay separate. FemalePain (player FSM clip swap) and Women `Voice` (NPC FSM clip swap) likewise; `VoiceOf(identity)` is
  the shared query.
