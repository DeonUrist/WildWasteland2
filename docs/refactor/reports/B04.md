## Contracts / events
- Provided: `ISaves` (state, kind, progress, autosave due/deferral, active file/name, CanSaveNow, RequestAutosaveSoon).
- Published: `BeforeSerialize` (after the journal is prepared), `AfterSerialize` (now right after native serialization
  finishes, Ok=true; a save that began but did not finish sends Ok=false in its finally), `SavePresentation`
  (Saving: Begin .1 / Progress .25 / .75 / End; Idle: autosave countdown text, End clears).
- Subscribed: `CombatActivity`, `WeaponFired`, `NpcStateChanged` (Combat) -> autosave deferral; `SaveBus.FailureReported` -> transaction failure (W0-A request 2).
- Consumed: `INotifications` (fallback to the old message log while HUD does not provide it).

## Denis in-game test steps
1. New world -> manual save (named) from pause menu -> quit to title -> Continue loads it; LOAD GAME shows the library.
2. Wait for an autosave: countdown under the compass, 30/15 s notices, "The game will save now", SAVING/AUTOSAVING overlay; start a fight during the countdown -> "Autosave deferred"; fight from a vehicle with patrols -> deferred.
3. Save As a new snapshot of a world that has NPC senses, patrols, POI, fog and quest crew: the new save loads with all of them (sidecars copied; senses header remapped).
4. Drive far (terrain tiles stream), come back, save and reload: looted/opened sites stay as left (WorldHistory).
5. Delete a save, restore a backup from the library (title menu). Kill the game during a save once -> next start recovers ("Interrupted save recovered" warning).
6. Toggle Saves off in the module list (not while saving): native 10-slot menus work; back on: library returns.
7. Debug VerboseLevel 0/1/2: `[Saves]` lines appear only at 1 (main) / 2 (terrain detail).
