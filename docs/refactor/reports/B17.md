## Structure (README 6.12: one folder per mod)
`src/Modules/Compatibility/`
- `CompatibilityModule.cs` entry: lifecycle, config binding, settings rows, providers. Per-mod bridges are declared in its
  constructor as `OptionalBridge`s (start order: SigmaMod, VistasWorldGen, ApocaDustStorm, Apocaspawner, Apocapocket, Apocatalker,
  ChaseCamera, BloodFX, DogCompanion, WeaponsPack); Engine Sim, ApocaLanguage and CaveDarkness keep Codex's dedicated code.
- `OptionalBridge.cs` (new): one bridge = own `CompatibilityScope` (patches/jobs/hooks/events/providers of that mod only),
  `[Compatibility / <Mod>] Enabled` + System settings row, live restart (`Hooks.ApplyUsed` after a restart).
- `CompatibilityHost.cs` (new): "is the module this bridge serves running" by module id through `ModuleHost` (old id first, final
  id second: PlayerBody/Presentation, NPC/NPCAI, Guns/Gunplay, CleanHUD/HUD, Patrols, Survival, Quests). Bridges act only while
  their host runs, as when the host installed them.
- `CompatibilityScope.cs`: + `Mod` name.
- `LegacyEntries/` (moved from the five `_from*` folders): the old entry partial files (CleanHUD, Guns, NPC, PlayerBody, Survival)
  with every method emptied except CleanHUD `InitCompatibilityApocasaver` (needs the HUD's own loading screen, B17-10). Wave C deletes them.
