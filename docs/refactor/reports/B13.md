# B13 POI — owned implementation completion

The POI package now owns world discovery, custom encounter decisions, town generation/construction, template intent, reusable layout/catalog backends and all town assets. Runtime NPC movement and population remain with NPCAI; native ItemSpawner manipulation and spawn-profile catalogs remain with Loot. Real provider/consumer interfaces replace the earlier cross-owner partial implementations.

## Completed behavior

- `IWorldLocations` includes remembered camps/POIs, accepted town plans and active custom registrations. `IWorldDiscovery` supplies detached camp geometry and live resident observations to Patrols. Discovery uses the shared Core WorldIndex instead of another recurring scene traversal. Camp residents are managed records, with no extra component attached to saved native actors. Loaded/unloaded/ready/dead distinctions remain.
- `TownNavGeometry` copies street/lot/polygon/patch data; NPCAI owns live street routing, instance overlays, entry approach and provider recovery. POI construction controls the lifetime using narrow work handles. POI supplies numeric cardinal perimeter queries and readiness callbacks. Original native arrays restore before removal; contexts release on streaming/shutdown and recreate on provider return.
- POI-owned town and marker orchestration calls actual Loot `INativeSpawners`/`INativeSpawnCatalog`. Native selector indices/weights, committed marker identities, counters, completed groups and saved names are retained. `INativePopulation` owns location arrival, readiness, hearing and native spawn pacing.
- TownStore **v9** accepts only the current format, snapshots normalized template JSON and persists external companion flags. Editing a template changes future decisions rather than saved towns. Required merchants, permitted native/custom POIs, weighted template selection, lot ranges, population/loot percentages, walls and external parking companion lists are used. Every external companion is an independent persisted lot with its own native spawner progress and navigation discovery, outside the wall footprint.
- Explicit `ITownPrefabCatalog` registrations supply real static prefab objects before first graph capture; matching native .wwnav maps and measured entrances are required. Unavailable custom assets fail explicitly. The built-in gas-station shell participates in that same catalog.
- `IPoiAuthoring` exposes detached sites/layout JSON/catalog descriptions and validated preview/save operations; save rebuilds all instances of the reusable type without rerolling committed marker progress. `IGasStationAuthoring` exposes the real test backend settings/status. Tools owns the editor UI and draft undo stack.
- War Rig encounter code and its prepared abandoned-rig JSON are POI-owned. The actual authored vehicle queue applies setup/cargo overrides. Vehicle attachments are queried through the Vehicles provider; saved native actors use Core registration. HUD receives stable world positions through `IEncounterNotices`.
- Town marker labels/colors/icons/exclusions/visibility use real HUD services. Marker exclusions are reapplied when HUD restarts. Town stop lifecycle is a typed event consumed by Patrols. Town route hints register against the actual routing provider and withdraw cleanly.
- Generation tuning moved out of player settings to POI tools settings; ineffective legacy layout knobs and superseded global population/loot controls removed. Optional world generation uses Compatibility facts and Core WorldTiles edits. POI main-action logs obey Debug policy.

## Persistence and assets

All persistent POI/town/encounter/location/marker progress is part of the selected ES3 save transaction; no sidecar registration, external fallback or migration is restored. Authored templates/layouts and derived navigation maps remain external assets by design. Corrupt embedded records latch failure and prevent replacement. All town models/names/gate textures/layout defaults moved to `POI/Embedded`; the prepared encounter definition is a new POI asset. Build index rows are unique and all **11** staged POI payload hashes equal their sources.
