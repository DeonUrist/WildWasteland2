still makes the OLD service call at the same place. The consumer owns both its old service implementation and its new
subscription, so the consumer decides: when it subscribes to the event for a purpose, it turns its old method into a no-op
`[Obsolete]` forwarder for that purpose (or does not subscribe). Never both.
