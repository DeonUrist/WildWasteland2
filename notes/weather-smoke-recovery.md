## Rendering cause and replacement

Revision 3 moved a CameraTarget read/material-blit/copy to AfterImageEffects and submitted weather geometry afterward. The material's scene input defaults to white. With the game's post-processing render-target path, that scene-color read/composition did not preserve the actual rendered terrain/objects; screenshots show white silhouettes while later dust/HUD still render. The white regression belongs to that new camera-buffer path, not replaced game textures or saves. An editor scene without the game's post-processing did not establish compatibility.

The failed path has been removed, not layered with another grading fix. Atmosphere now draws a clip-space quad at BeforeForwardAlpha using premultiplied alpha-over blending and opaque depth only. There is no scene-color sampler, CameraTarget blit, copy, temporary full-resolution color target, terrain recoloring, exposure override or late weather draw buffer. Native transparent rendering/post-processing follows normally. Exact game appearance still requires Denis's retest.

During authoring, a direction-color diagnostic proved the fullscreen ray was vertically inverted: upper pixels pointed downward. Depth UV and ray now use the same top-origin correction. Separate layer isolation located vertical curtain lines in the fog, not particle placement. Repeating world-noise integration was removed; sky texture tiling/sine bands were replaced with continuous 3D value noise. Temporary diagnostic shaders/builder changes lived only in the external authoring project and were restored; final authoring sources match the checkout.

## Reference inspection

The reference [HaboobWall](https://github.com/Jaime-Wolf/Dust-storms/blob/927962f67024de217ced655c8a2622300ebd3c45/Source/HaboobWall.cs) uses sorted particles, depth fades and multiple depth bands; [HaboobTransition](https://github.com/Jaime-Wolf/Dust-storms/blob/927962f67024de217ced655c8a2622300ebd3c45/Source/HaboobTransition.cs) stages wind/palette/light/fog by distance. These general techniques explain its coherent arrival. Our particle placement/shaders/noise are independently authored; no reference code, formulas or atlas adapted/bundled. Its license still requires author permission for adaptation/bundling. Unity's official PPv2 PostProcessLayer source describes its command-buffer render targets/final-blit handling; see https://github.com/Unity-Technologies/PostProcessing/blob/v2/PostProcessing/Runtime/PostProcessLayer.cs .
